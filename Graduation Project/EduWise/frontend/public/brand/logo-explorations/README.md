# EduFlow AI — Logo explorations

Six alternatives using the existing palette: #315DA8, #F2B880, #14243B, #F8F9FF.
Fonts: Plus Jakarta Sans and IBM Plex Sans Arabic (the site's existing licensed fonts).

Each concept includes editable SVG symbols in color, mono and reversed treatments; transparent PNG wordmarks; and a PNG icon. The numbered comparison board matches the filenames.
SVG symbols contain only native paths/shapes, with no font or external resource dependency. PNG wordmarks are raster exports of the local fonts.
