PART 1 — Modeling & Optimization

1. Model Selection
   Select suitable regression algorithms for the housing price prediction problem.
   Define the models that will be implemented and evaluated.

2. Model Implementation
   Implement the selected regression models using the prepared ML data.
   Ensure that each model receives the correct training and testing inputs.

3. Model Training
   Train the selected models using the training dataset.
   Generate predictions that can be evaluated using the defined metrics.

4. Cross-Validation
   Apply cross-validation to obtain more reliable estimates of model performance.
   Use the training data during cross-validation without exposing the test set.

5. Hyperparameter Tuning
   Tune the important hyperparameters of the selected models.
   Search for parameter combinations that improve validation performance.

6. Model Comparison
   Compare the trained models using the agreed evaluation metrics.
   Analyze their performance and generalization results.

7. Final Model
   Select and train the final model based on the modeling results.
   Prepare the optimized model for final testing and deployment.

8. Final Evaluation
   Evaluate the final model on the unseen test dataset.
   Report the final performance using the agreed regression metrics.
