# Depi-Projects-AI

A collection of projects developed during the **Digital Egypt Pioneers Initiative (DEPI)**.

This repository contains projects covering different areas of Python, Data Analysis, Artificial Intelligence, and Machine Learning.

## Projects

### Python

Python projects focused on programming fundamentals, Object-Oriented Programming, and software development concepts.

### Data Analysis

Projects covering data cleaning, exploration, visualization, and analysis using Python.

### Machine Learning

Projects focused on machine learning concepts, data preprocessing, model development, evaluation, and deployment.

### Deep Learning

Projects covering deep learning and its applications, including:

* Computer Vision
* Natural Language Processing
